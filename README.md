# cligMET public static site

This is the same cligMET v3.2-style interface, changed to read one public JSON snapshot.

1. Open `config.js`.
2. Replace `YOUR-CLIGMET-DATA-SERVICE` with the name of your Render receiver service.
3. Copy `index.html` and `config.js` into the repository used by your existing Render Static Site.
4. Commit and push.

The public page is read-only. Change the station, forecast controls and calibration settings on the home dashboard.
